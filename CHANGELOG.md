# Changelog

## 1.0.0 — 2026-10-22

Initial Chrome extension package.

- Added a Manifest V3 toolbar action that opens the bridge on Google AI Studio.
- Kept the three-button flow: Link folder, Send context, and Apply latest reply.
- Preserved automatic context filling while keeping existing chat drafts.
- Added latest-model-only code fetching, including AI Studio's plain `FILE:` headers and JSON manifests.
- Kept file previews, conflict checks, multi-batch undo, recovery downloads, and rollback reporting.
- Included a movable panel and a draggable minimised icon.
- Packaged installation instructions and regression tests for repository use.
